# Cursor Image Preview

Небольшой Vanilla JavaScript эксперимент: при наведении на название элемента рядом с курсором появляется связанное с ним изображение.

## Что демонстрирует проект

- поиск элементов через `querySelector` и `querySelectorAll`;
- перебор коллекции через `forEach`;
- события `mousemove` и `mouseleave`;
- изменение CSS-свойств из JavaScript;
- динамическое формирование пути к изображению.

## Статус

Эксперимент / учебная наработка. Основная механика работает, проект используется в портфолио как пример работы с DOM и событиями мыши.

## Технологии

HTML, CSS, JavaScript
